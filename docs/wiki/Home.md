# Наш дом 🏡

Домашний органайзер в Telegram для одного человека или семьи. Помогает вести дела, покупки, запасы, меню, бюджет и уход за питомцами.

> Проект развивается. Часть функций уже доступна, часть ещё проверяется и дорабатывается.
