# Возможности

| Раздел | Назначение |
| --- | --- |
| **Главная** | Общая точка входа в приложение |
| **Запасы** | Учёт продуктов и бытовых вещей, история расходования, аналитика и прогноз окончания запасов |
| **Покупки** | Общий список того, что нужно купить |
| **Дела** | Домашние задачи |
| **Меню** | Планирование питания на неделю |
| **Кошки** | Данные о питомцах и расписание ухода |
| **Бюджет** | Учёт расходов |

## Что появится позже

- Отметка «Закончилось раньше» у продукта
- Более точные рекомендации для закупок
- Подтверждение или изменение предложенного количества
- Свободный ввод событий через ИИ
- Дополнительные автоматизации и напоминания

Это планы, а не уже работающие возможности. Актуальные задачи: [Issues](https://github.com/p0kt1e/nash-dom-open-source/issues).
