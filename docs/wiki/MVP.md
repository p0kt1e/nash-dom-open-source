# MVP — Наш дом

**Цель:** одна универсальная версия кода для собственного Telegram Mini App и других независимых установок. У каждой установки свой бот, конфигурация и база D1. Личные данные не хранятся в публичном репозитории.

## Статусы

- **Есть в коде** — функциональность найдена в публичном исходном коде, но ещё не означает, что проверена в Telegram
- **Частично** — есть часть сценария, но не все требования выполнены
- **Нет** — нужной реализации в текущем публичном коде не найдено
- Все проверки полноценной работы с реальной D1/Telegram выполняются отдельно

## Главная

- [ ] **Частично** — сводка дел именно на сегодня: сейчас есть только общее количество выполненных задач, без сроков
- [ ] **Нет** — список того, что нужно купить, на главной
- [ ] **Частично** — заканчивающиеся запасы: на главной показаны корм и наполнитель, общая сводка по категориям отсутствует

## Запасы

- [ ] **Частично** — добавление и изменение товаров: добавление есть, редактирования существующей карточки нет
- [ ] **Есть в коде** — учёт количества и единиц (г, кг, л, мл, шт)
- [ ] **Есть в коде** — пополнение и списание запасов
- [ ] **Частично** — история изменений: API /api/inventory/:id/history есть, экран истории отсутствует
- [ ] **Есть в коде** — предупреждение по порогу «мало»

## Покупки

- [ ] **Есть в коде** — добавление и удаление товаров
- [ ] **Есть в коде** — отметка купленного
- [ ] **Нет** — перенос купленного товара в запасы

## Дела

- [ ] **Есть в коде** — создание и выполнение задач
- [ ] **Нет** — повторяющиеся домашние дела (повторение ухода за питомцами реализовано отдельно)
- [ ] **Нет** — назначение задачи участнику семьи

## Меню

- [ ] **Есть в коде** — планирование блюд по датам, включая неделю
- [ ] **Есть в коде** — изменение блюда через повторное сохранение для даты и приёма пищи

## Кошки

- [ ] **Частично** — карточки питомцев: просмотр и изменение заметок есть, создание/редактирование остальных полей нет
- [ ] **Есть в коде** — расписание ухода с интервалом в днях
- [ ] **Есть в коде** — отметка выполненного ухода

## Бюджет

- [ ] **Есть в коде** — добавление и удаление расходов
- [ ] **Есть в коде** — категории расходов (свободный ввод)
- [ ] **Есть в коде** — месячные лимиты по категориям
- [ ] **Есть в коде** — сводка расходов за месяц и по категориям

## Что не входит в базовый MVP

- ИИ и свободный ввод событий
- Умные закупки и адаптивный прогноз расхода
- Автоматические Telegram-напоминания
- Расширенная аналитика и редизайн

## Порядок работ

1. Проверить совпадение личной рабочей версии с публичной и сохранить личные данные/конфигурацию перед синхронизацией
2. Закрыть пробелы существующих функций MVP, прежде всего покупки → запасы, редактирование карточек и задачи семьи
3. Собрать полноценную главную страницу на основе этих данных
4. Проверить все сценарии в личной Telegram-версии и исправить найденные ошибки
5. Зафиксировать MVP как готовый к ежедневному использованию; только затем брать функции из следующего этапа

**Правило готовности:** отмечать чекбокс только после проверки сценария в установленном приложении. Наличие кода само по себе не означает завершённую задачу.
